# Fastlane Screenshots

This directory is populated from `branding/screenshots/exports/app-store/` before upload.

To refresh source exports on demand, use the external generator:

```bash
CUE_SCREENSHOT_STUDIO_DIR=/path/to/cue-screenshot-studio make screenshot-refresh
```

See [the branding workflow](../../branding/README.md) for details. Existing
exports can be uploaded without the generator.
